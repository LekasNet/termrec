# termrec — запись терминальных сессий

`termrec` записывает работу в терминале и создаёт чистые отчёты в Markdown и TXT.
В отчёт попадают команды, их вывод, задания, заметки и сохранённые фрагменты кода.
Оформление терминала, приглашение оболочки, цветовые последовательности и перерисовка
экрана не засоряют результат.

## Установка

### Arch Linux

```bash
sudo pacman -U ./termrec-0.4.0-1-any.pkg.tar.xz
```

### Debian и Ubuntu

```bash
sudo apt install ./termrec_0.4.0-1_all.deb
```

Проверьте установку:

```bash
rec --version
rec help
```

## Начало и завершение записи

```bash
rec start lab1

whoami
pwd
ls -la

rec stop
```

По умолчанию материалы сохраняются в:

```text
~/Documents/LinuxWorks/ГГГГ-ММ-ДД/имя-сессии/
```

После `rec stop` создаются `lab1.md` и `lab1.txt`. Исходный вывод терминала остаётся
в `session.raw`.

Для Bash и zsh запись интерактивна. Команда `rec start` не меняет `.bashrc` и `.zshrc`.
Можно выбрать оболочку явно:

```bash
rec start lab1 --shell bash
rec start lab1 --shell zsh
```

## Структура отчёта

```bash
rec task "Пользователи"
whoami
id

rec note "Проверить права на каталог"
rec sep

rec code ~/.bashrc bash ".bashrc"
```

- `rec task "Название"` создаёт раздел.
- `rec note "Текст"` добавляет пояснение.
- `rec sep` добавляет горизонтальный разделитель.
- `rec code <файл> [язык] [название]` копирует текущую версию файла и включает её
  в экспорт как блок кода.

Пример фрагмента Markdown-отчёта:

```console
$ whoami
> user
$ id
> uid=1000(user) gid=1000(user) groups=1000(user)
```

## Продолжение завершённой записи

Продолжение добавляет команды в ту же сессию и обновляет её отчёты:

```bash
rec start lab1 --continue
```

Если одинаковых имён несколько, укажите каталог сессии:

```bash
rec start ~/Documents/LinuxWorks/2026-10-06/lab1 --continue
```

## Несколько терминалов

Запись поддерживает терминалы, открытые из активной сессии. Второй терминал наследует
сведения о ней через окружение.

```bash
# Первый терминал
rec start lab1 -terms
gnome-terminal &

# Второй терминал
rec attach
echo "Команда из второго терминала"
rec stop
```

`rec attach` запускает записываемую дочернюю оболочку во втором окне. `rec stop` в
этом окне завершает только подключённый терминал. Основная сессия продолжает работу.

Дополнительные исходные логи лежат в `terminals/` внутри той же папки сессии и
автоматически включаются в общий экспорт.

## Названия терминалов и рабочие каталоги

Добавьте `-terms`, чтобы у каждой части отчёта появлялось название терминала и TTY.
Добавьте `-path`, чтобы перед командами вне домашней папки отображался текущий каталог:

```bash
rec start lab1 -terms -path
```

Пример:

```console
# /home/user/project
$ git status
> On branch main
```

## Защита чувствительных данных

`termrec` сохраняет вывод псевдотерминала и не записывает stdin. Пароль, который
программа вводит при отключённом echo, не сохраняется как ввод. Тем не менее секрет
может попасть в `session.raw`, если его печатает сама программа.

Во время записи можно исключить команды из Markdown и TXT:

```bash
rec pause
# действия с чувствительными данными
rec resume
```

Также можно скрыть текст или регулярное выражение при экспорте:

```bash
rec redact
rec redact --regex
rec redact --list
rec redact --remove 1
```

`pause` и `redact` не очищают уже созданный `session.raw`. Перед передачей папки
сессии проверьте исходные логи и сохранённые файлы кода.

## Экспорт, поиск и восстановление

```bash
# Экспорт выбранной сессии
rec export all --session /путь/к/сессии

# Экспорт одного задания или конкретных команд
rec export md --task 2 --session /путь/к/сессии
rec export txt --commands 1,3,5 --session /путь/к/сессии

# Список и просмотр сессий
rec list
rec show /путь/к/сессии

# Вывод исходной записи в терминал
rec replay /путь/к/сессии
```

## Платформы

- Linux и macOS: интерактивная запись Bash и zsh.
- Другие POSIX-оболочки: `rec run <имя> -- <команда>` для записи отдельной команды.
- Windows: `rec run <имя> -- powershell -NoProfile -Command <команда>` для записи
  отдельной команды. Интерактивная запись PowerShell и cmd пока не поддерживается.

Терминальный эмулятор не важен: поддерживаются GNOME Terminal, Kitty, iTerm2,
Terminal.app, Windows Terminal и другие, если используется поддерживаемый режим записи.
